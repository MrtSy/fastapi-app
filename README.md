# FastAPI Todo API

FastAPI, PostgreSQL ve Docker Compose ile geliştirilmiş REST API.

## Özellikler
- Todo ekleme, listeleme, güncelleme, silme (CRUD)
- PostgreSQL veritabanı
- Docker Compose ile tek komutta çalıştırma

## Kurulum

```bash
docker compose up --build -d
```

## Kullanım

http://localhost:8000/docs adresinden API'yi test edebilirsiniz.

## Teknolojiler
- FastAPI
- PostgreSQL
- SQLAlchemy
- Docker
